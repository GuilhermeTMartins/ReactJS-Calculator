A simple and quick project built with ReactJS as part of my learning journey. This application simulates a functional calculator with basic math operations such as addition, subtraction, multiplication, and division.

🚀 Technologies Used
ReactJS

JavaScript (ES6+)

HTML5 + CSS3 (responsive design)

📌 Features
Clean and responsive interface

Basic operations: add, subtract, multiply, divide

Functional components and use of React Hooks (useState)
